# מדף V2 — כללי מוצר

- כל המחירים באגורות שלמות; התצוגה בשקלים. מע״מ מעוגל פעם אחת בסיכום ההזמנה.
- מחיר ושיעור מע״מ מקוריים נשמרים בשינוי הזמנה. פריט חדש מתומחר בעת יצירת ההצעה.
- המינימום התקף נבדק ביצירה ובשינוי.
- כל הזמנה שנשלחה לפני אישור העסק נשארת ממתינה להכרעה גם לאחר אישור הזמנה אחרת.
- אישור עסק נעשה דרך אישור הזמנה ראשונה. אין כפתור עקיפה.
- מוצר מושבת שכבר בהזמנה נשמר; אפשר להפחיתו או להסירו. אי אפשר להוסיף אותו או להגדיל כמותו.
- בקשה במצב stock_conflict נחשבת פתוחה וחוסמת ליקוט ובקשה נוספת.
- דחיית בקשה אינה משנה מלאי. ביטול הזמנה או דחיית הזמנה ראשונה מחזירים מלאי בדיוק פעם אחת.
- מידע היסטורי שומר snapshot. שינוי פרופיל אינו משנה כתובות בהזמנות קיימות.
- מצב הדמו מבודד מהחיבור החי. דמו אינו אימות OAuth, הרשאות או תחרות בענן.
- Reorder, מועד אספקה, צירוף משתמשים נוספים ושליחת WhatsApp חיה מחוץ לסבב. אירועי התראות ותור מוכנים לחיבור ספק.
