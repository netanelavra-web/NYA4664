# 50 פרטי השימושיות — מדף V2

זהו רישום הדרישות. סטטוס האימות הסופי מופיע בדוח QA ולא נגזר מעצם הופעת הפריט כאן.

1. סימון כרטיס מוצר שנבחר: צבע וטקסט, ללא שינוי גודל.
2. משוב מיידי לכמות ולסכום; תנועה מופחתת נתמכת.
3. הקלדה ישירה בכמות ומקלדת מספרית.
4. Living Order הוא משטח רציף עם כפתור ומחווה.
5. סכום חסר למינימום לפני מע״מ.
6. Quick View שומר גלילה ומחזיר focus.
7. רמז המשך מדף וכפתורי גלילה בדסקטופ.
8. הסרה עם אפשרות החזרה בכפוף למלאי.
9. הערה נשמרת כחלק מטיוטה מבודדת לעסק.
10. שליחה עם מצב המתנה וחסימת כפילות.
11. השוואת מקור ומוצע בבקשת שינוי.
12. עריכת מוצר עם תצוגה מקדימה.
13. תיקון מלאי מציג לפני, שינוי ותוצאה.
14. סיום טיפול בתור ללא קפיצה לפריט הבא.
15. זיכרון חיפוש, סינון, גלילה ובחירה.
16. חיפוש מק״ט סלחני לרווחים ומקפים.
17. הרחבת חיפוש כשסינון מצמצם תוצאות.
18. הצגת ארגזים ויחידות יחד.
19. חריגת מלאי אינה מתוקנת בשקט.
20. אישור מחיר שהשתנה לפני שליחה.
21. מוצר שאזל נשאר מוסבר בעגלה.
22. כשל שליחה משמר עבודה ומפתח ניסיון.
23. הסבר שהזמנה מקורית בתוקף כשבקשה ממתינה.
24. חסימת פעולה עם סיבה ודרך להתקדם.
25. טיוטות עריכה נפרדות משמירת שרת.
26. אישור לפעולות בעלות השפעה משמעותית.
27. עדכונים חיים אינם מזיזים יעד לחיצה.
28. שמירת הקשר פנימי ופירוט פתוח.
29. תמיכה במקלדת מובייל וסדר Tab.
30. משוב ושגיאות סמוך לפעולה.
31. הבחנה בין טיוטה להזמנה שנקלטה.
32. חיווי שחזור טיוטה עם מחיקה יזומה.
33. חיווי מצב חיבור והמשך עבודה מקומית.
34. עדכון טיוטה מלשונית נוספת ללא דריסה שקטה.
35. קונפליקט גרסה לפני החלטת מנהל.
36. זהות עסק ברורה ובידוד חשבונות.
37. כתובת באישור הזמנה ועריכה לפני שליחה.
38. תמונה מוגדלת וטעינה כושלת בטוחה.
39. שטחי תמונה יציבים בזמן טעינה.
40. העתקת מספר הזמנה וקישור לפרטים.
41. תאריכים קריאים עם זמן מדויק בפרטים.
42. חיפוש הזמנות לפי מספר, עסק, איש קשר וסינון טווח.
43. סינונים גלויים ואפשרות ניקוי.
44. זמן המתנה ומיון בקשות.
45. ציר זמן עם מבצע, פעולה ומועד.
46. בדיקת זמינות מול בקשת שינוי.
47. העלאת תמונה עם תצוגה מוקדמת וטיפול בכשל.
48. בדיקת SKU כפול ליד השדה וגם בשרת.
49. dialog focus trap, Escape ו-focus restore.
50. ניגודיות, אזורי לחיצה, הגדלת טקסט ופעולות שאינן תלויות במחווה.
